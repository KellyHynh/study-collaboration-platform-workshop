# Upload Object

A sample course thumbnail is uploaded to verify that the bucket can store KnoVerse assets.

#### Step 1: Open the Thumbnail Location

Navigate to:

courses/thumbnails/

#### Step 2: Upload the File

Click Upload and select a course thumbnail file.

The test object used in this implementation is:

course-react.png

#### Step 3: Complete the Upload

Click Upload and wait until AWS reports that the upload has completed successfully.

The resulting object key is:

courses/thumbnails/course-react.png

The final structure becomes:

knoverse-assets-2026/
└── courses/
    └── thumbnails/
        └── course-react.png

Expected result:

The course-react.png object is visible inside the courses/thumbnails/ location.
