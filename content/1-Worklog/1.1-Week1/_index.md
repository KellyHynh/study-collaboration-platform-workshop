### Week 1 Achievements:

* Understood the basic concepts of cloud computing and AWS.

* Became familiar with the main AWS service groups:

* Compute

* Storage

* Database

* Networking

* Security

* Monitoring

* Became familiar with the AWS Management Console and basic service navigation.

* Learned the basic concepts of IAM, including:

* Users

* Groups

* Policies

* Roles

* Practiced basic IAM resource management.

* Installed and configured AWS CLI and practiced basic commands for checking AWS account and region information.

* Gained an initial understanding of the roles of EC2, S3, and RDS in a cloud-based application.

* Practiced designing a simple AWS architecture to understand how different services can work together.

* Continued university study activities alongside AWS learning.

* Practiced LeetCode problems during the week to maintain algorithm and problem-solving skills.
