Phần này giới thiệu các bài blog đã được đăng trên [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj).

### [Blog 1 - Tự động hóa xử lý sự cố CI/CD với AWS DevOps Agent và GitHub](3.1-Blog1/)

Bài blog giới thiệu AWS DevOps Agent và cách sử dụng AI để tự động điều tra nguyên nhân khi GitHub Actions gặp lỗi. Bài viết tập trung vào cách AWS DevOps Agent kết hợp với GitHub App, Amazon CloudWatch và GitHub MCP Server để đọc workflow logs, source code, commit history, phân tích nguyên nhân và đề xuất Pull Request khắc phục lỗi. Qua đó, bài viết cũng đề cập đến mô hình Human-in-the-loop và các nguyên tắc bảo mật như Least Privilege và xác thực Webhook.

### [Blog 2 - Xây dựng AI Agent cho bài toán phân loại dữ liệu theo lĩnh vực](3.2-Blog2/)

Bài blog tìm hiểu cách xây dựng AI Agent phục vụ bài toán Domain-Specific Classification bằng cách kết hợp Amazon Bedrock với các dịch vụ Serverless như Amazon S3, EventBridge, Lambda, SQS, DynamoDB và CloudWatch. Bài viết tập trung vào khả năng của AI Agent trong việc phân tích dữ liệu, sử dụng công cụ, đưa ra quyết định cùng Confidence Score và lưu lại reasoning cũng như nguồn tham khảo. Qua đó, bài viết làm rõ cách kiến trúc Serverless có thể hỗ trợ xây dựng hệ thống AI có khả năng mở rộng và dễ theo dõi.

### [Blog 3 - Phân loại file bằng AI với AWS](3.3-Blog3/)

Bài blog tìm hiểu cách sử dụng AI để tự động phân loại tài liệu dựa trên nội dung bên trong file thay vì chỉ dựa vào tên file. Bài viết trình bày kiến trúc kết hợp AWS Transfer Family, Amazon S3, EventBridge, SQS, Lambda, Amazon Textract và Amazon Bedrock để xây dựng một pipeline xử lý tài liệu theo mô hình Event-driven và Serverless. Qua bài viết, mình tìm hiểu thêm cách kết hợp Generative AI với các dịch vụ AWS để giải quyết những bài toán xử lý dữ liệu thực tế.
