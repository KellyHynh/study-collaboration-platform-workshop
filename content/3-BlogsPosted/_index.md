This section introduces the blogs I have written and posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj), focusing on AWS services, cloud architecture, AI, and practical applications of AWS technologies.

### [Blog 1 - Automate CI/CD Troubleshooting with AWS DevOps Agent and GitHub](3.1-Blog1/)

This blog explores how **AWS DevOps Agent** can be integrated with GitHub and CI/CD workflows to automatically investigate pipeline failures. It introduces the roles of GitHub App, Amazon CloudWatch, and GitHub MCP Server in collecting information, analyzing failures, and creating Pull Requests with potential fixes. The blog also discusses the Human-in-the-loop approach and security best practices such as Least Privilege and Webhook authentication.

### [Blog 2 - Building AI Agents for Domain-Specific Classification at Scale](3.2-Blog2/)

This blog explores how AWS can combine **Amazon Bedrock** with serverless services to build AI Agents for domain-specific data classification. It explains how Amazon S3, EventBridge, Lambda, SQS, DynamoDB, and CloudWatch work together to create a scalable and asynchronous processing pipeline. The blog also highlights AI reasoning, tool use, confidence scores, audit trails, and the importance of transparency when applying AI to real-world domains.

### [Blog 3 - AI-powered File Classification with AWS](3.3-Blog3/)

This blog discusses an AI-powered approach to automatically classify files based on their actual content rather than relying only on filenames. It introduces an event-driven architecture using **AWS Transfer Family, Amazon S3, EventBridge, SQS, AWS Lambda, Amazon Textract, and Amazon Bedrock**. The blog focuses on how these services can work together to receive, process, extract information from, and classify documents in a scalable serverless workflow.
